# Mods aus der Toolbox

Liegt hier eine Datei `mod.json`, lädt das Spiel sie beim Start – für alle Spieler:innen.

So kommt sie hierher:
1. Toolbox öffnen (`editor.html`), Werte und Grafiken ändern.
2. „Exportieren“ tippen → Datei `mod.json` wird heruntergeladen.
3. Auf GitHub in diesen Ordner hochladen (Add file → Upload files) – eine vorhandene `mod.json` wird dabei ersetzt.
