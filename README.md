# Rift Defense

> ⚠️ **Early Development** – Das Spiel befindet sich in einer frühen Entwicklungsphase.
> Grafiken sind Platzhalter, Balancing und Inhalte ändern sich laufend.

Ein Tower-Defense-Roguelite fürs Handy (Querformat).

Du regierst als König eine mittelalterliche Stadt. Jede Nacht öffnet sich vor den Toren ein **Rift**
und verwandelt das Land – in eine Urzeit voller Dinosaurier, eine Roboter-Fabrik oder eine
Mondlandschaft mit Aliens. Baue jede Nacht neue Türme, halte das Tor und baue mit der Beute
deine Stadt dauerhaft aus.

## Features

- **Tag:** eine eigene Stadt mit Bauplätzen, Gebäuden, Upgrades und Forschung – sie schaltet nach und nach neue Türme frei
- **Nacht:** jede Nacht eine neue Karte mit eigenen Feldern, Gegnern und Bossen
- Boden- und Fluggegner, verschiedene Turmarten mit mehreren Stufen
- Der König verteidigt das Tor – oder zieht los, um Rohstoffe abzubauen
- Upgrade-Karten in vier Seltenheitsstufen, Story-Nächte mit Belohnungen
